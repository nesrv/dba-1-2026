# DBA1 — Администрирование PostgreSQL 16 (базовый курс)

Учебные материалы по **базовому курсу администрирования PostgreSQL 16** (линейка **DBA1**, Postgres Professional): слайды, Marp-презентации и тексты для лектора.

Курс рассчитан примерно на **3 дня** и даёт обзор архитектуры, установки и настройки сервера, организации данных, мониторинга, доступа, резервного копирования и репликации.

> Некоммерческое использование разрешено; коммерческое — только с письменного разрешения компании.

## Как смотреть презентации

В каждой папке `lN` лежит Marp-файл `presentation.md`: слайды подключаются как фоновые PNG.

1. Установите [Marp for VS Code](https://marketplace.visualstudio.com/items?itemName=marp-team.marp-vscode) (или CLI Marp).
2. Откройте `lN/presentation.md`.
3. Включите предпросмотр Marp / экспорт в PDF или HTML.

Пример фрагмента:

```markdown
---
marp: true
paginate: false
---

![bg contain](slide1.png)
```

Тексты для ведения занятия — в `lN/speaker-notes.md` (разговорный стиль, команды, факты, разбор практики).

5. **Надёжность** (l14–l16) — бэкапы, физическая и логическая репликация.

# Практическая работа

Домашнее / аудиторное задание по курсу DBA1: установка и `psql`, конфигурация, MVCC/VACUUM, буферы и WAL, организация данных, мониторинг, доступ, бэкапы и репликация (**части 1–16**).

> Подсказки по утилитам и путям ориентированы на учебную ВМ с PostgreSQL 16 (Ubuntu/пакетная установка).

## Часть 1. Контрольные суммы

**Задача:** включить расчёт контрольных сумм в кластере.

1. Остановите сервер.
2. Проверьте, рассчитываются ли контрольные суммы в кластере.
3. Включите расчёт контрольных сумм.
4. Запустите сервер.

**Подсказка (п. 2–3):** используйте утилиту `pg_checksums`. Для запуска укажите полный путь:

```text
/usr/lib/postgresql/16/bin/pg_checksums
```

Документация: [app-pgchecksums](https://postgrespro.ru/docs/postgresql/16/app-pgchecksums)

## Часть 2. Настройка `psql`

1. Запустите `psql` и проверьте информацию о текущем подключении.
2. Выведите список баз данных в подробном виде.
3. По умолчанию `psql` использует команду `less` для постраничного просмотра результатов. Замените её на `less -XS` и снова выведите подробный список баз данных.
4. По умолчанию приглашение `psql` показывает только имя базы данных. Настройте вид приглашения так:

   ```text
   пользователь@база=#
   ```

5. Настройте `psql` так, чтобы для всех команд выводилась длительность выполнения. Убедитесь, что при повторном запуске эта настройка сохраняется.

## Часть 13. Управление доступом

Настройте привилегии так, чтобы одни пользователи имели полный доступ к таблицам, а другие могли только запрашивать данные, но не изменять их.

1. Создайте новую базу данных и двух пользователей: `writer` и `reader`.
2. Отзовите у роли `public` все привилегии на схему `public`.  
   Выдайте роли `writer` обе привилегии на схему, а роли `reader` — только `USAGE`.
3. Настройте привилегии по умолчанию так, чтобы роль `reader` получала доступ на чтение к таблицам в схеме `public`, принадлежащим `writer`.
4. Создайте пользователя `w1`, включив его в роль `writer`, и пользователя `r1`, включив его в `reader`.
5. Под ролью `writer` создайте таблицу.
6. Убедитесь, что `r1` имеет доступ к таблице только на чтение, а `w1` — полный доступ, включая удаление.
